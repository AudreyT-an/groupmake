# 国内访问说明与部署指南（对应需求 9）

> 结论先说：**"必须开 VPN" 是两件事叠在一起造成的**——
> ① 网页引用了被拦截的 Google Fonts，导致页面一直等、白屏；
> ② `*.vercel.app` 这个域名本身在国内被污染/阻断，HTML 都请求不到。
> 第 ① 件已经在代码里彻底修好；第 ② 件需要换一个域名或换一个托管平台，本文给出 3 种做法。

---

## 一、为什么原来不开 VPN 就打不开

| 位置 | 问题 | 国内表现 |
| --- | --- | --- |
| `src/style.css` 第 1 行 `@import url('https://fonts.googleapis.com/...')` | Google Fonts 在中国大陆无法访问 | CSS 里 `@import` 是**阻塞渲染**的，浏览器会一直等这个字体样式表，等到超时（常见 20~30 秒）才继续渲染，看起来就是"一直在加载"甚至白屏 |
| 部署域名 `groupmake-xxx.vercel.app` | `vercel.app` 域名在大陆被 DNS 污染 | 连 HTML 都拿不到，浏览器报"无法访问此网站"，只能挂 VPN |
| 数据库 `xxx.supabase.co` | 部分运营商访问慢，Realtime 用 WebSocket | 登录转圈、状态不同步、偶发失败 |

小技巧：判断是哪一种很简单——**挂 VPN 打开后 F12 → Network**，如果有一个红色的 `fonts.googleapis.com` 请求卡在 pending，就是第 ① 类；如果一个请求都发不出去，就是第 ② 类（域名被墙）。

---

## 二、代码层已经改掉了什么（本次更新）

1. **彻底删除 Google Fonts 的 `@import`**，改用系统字体栈：
   `PingFang SC（苹果）→ 微软雅黑（Windows）→ 思源黑体/Noto Sans SC`。
   页面不再对任何境外域名发起请求，首屏立刻出内容。
2. `index.html` 里加入了**内联首屏骨架**（纯 CSS，不依赖任何外部文件）和内联 SVG 图标（`data:` 形式），
   网络慢时也能马上看到 "正在打开 GroupMate…"，而不是白屏。
3. 登录 / 首屏加载增加了 **15 秒超时 +「重试」按钮 + 中文提示**，连不上数据库时直接告诉你原因，
   不会无限转圈。
4. React、Supabase SDK、图标库全部由 Vite 打包进本地 JS，**没有任何 CDN 依赖**。

> 验证方法：浏览器 F12 → Network，过滤第三方域名，除 `*.supabase.co` 外应该**一条外部请求都没有**。

## 三、还差一步：让别人在国内能打开网址

### 方案 A（最快，约 10 分钟）：给 Vercel 绑定自己的域名

`vercel.app` 是共享域名，被墙的概率很高；**换成自己的域名后，大多数情况下国内可以正常打开**
（Vercel 官方文档也建议大陆访问使用自定义域名）。

1. 买一个便宜域名（阿里云 / 腾讯云 / Cloudflare，`.top`、`.xyz` 首年通常十几块）。
   - 服务器在境外，域名**不需要备案**（备案是针对放在国内机房的网站）。
2. Vercel 项目 → **Settings → Domains → Add**，填 `groupmate.你的域名.com`。
3. 按 Vercel 给的提示到域名商的 DNS 里加记录：
   - `CNAME` → `cname.vercel-dns.com`
   - 或 `A` → Vercel 提示的 IP
4. 等待生效（几分钟到几小时），Vercel 会自动签发 HTTPS 证书。
5. 回到 Supabase → **Authentication → URL Configuration**，把 **Site URL** 改成新域名，
   并在 Redirect URLs 里加上 `https://新域名/**`。
6.（可选）如果新域名解析仍不稳，把域名 NS 换到 Cloudflare 再解析。

> 实测提醒：直连 Vercel 的国内速度属于"能打开但不算快"，首屏 3~10 秒是常态；
> 如果老师现场要演示，建议配合方案 C（本地跑）做保底。

### 方案 B（最稳，推荐正式交付）：把静态文件放到国内可访问的托管

`npm run build` 之后 `dist/` 目录就是**纯静态文件**（HTML + JS + CSS），可以放到任何静态托管：

| 平台 | 国内访问速度 | 是否需要备案 | 备注 |
| --- | --- | --- | --- |
| 阿里云 OSS + CDN | 最快 | 自己域名需要 | 对象存储开启"静态页面"，上传 `dist/` 内容 |
| 腾讯云 COS / CloudBase | 最快 | 自己域名需要 | 同样支持静态网站托管 |
| Cloudflare Pages | 中等，一般能开 | 不需要 | 连接 GitHub 自动构建，和 Vercel 用法几乎一样 |
| Gitee Pages | 快 | 不需要 | 需要实名 + 仓库公开（课程演示可用） |

步骤（以 Cloudflare Pages 为例）：
1. `npm run build`（本地已装依赖时）。
2. Cloudflare Dashboard → Workers & Pages → Create → Pages → Connect to Git，选你的仓库。
3. Build command 填 `npm run build`，Output directory 填 `dist`。
4. 在 Environment variables 里填 `VITE_SUPABASE_URL`、`VITE_SUPABASE_ANON_KEY`（和 Vercel 一样）。

> 无论放哪里，**都要把 `VITE_SUPABASE_URL` / `VITE_SUPABASE_ANON_KEY` 配到该平台的环境变量里**，
> 否则网站会显示"完成云端配置后即可启用"。

### 方案 C（答辩保底）：本机 / 局域网演示

```bash
npm install
npm run dev      # 已配置 --host 0.0.0.0，同一 WiFi 下同学可用 http://你的内网IP:5173 打开
```
- 局域网内访问完全不经过外网域名，只会访问 `*.supabase.co`。
- 如果连 Supabase 都慢，可以提前登录好、把数据预加载在浏览器里演示，或用手机热点换一条线路。

## 四、顺手把 Supabase 也调快

1. **项目区域**：Supabase 新建项目时选 **Southeast Asia (Singapore)**，比美区快一个数量级；
   已经建好的也可以在 Project Settings 里查看区域。
2. **关闭邮箱验证**（避免注册后收不到验证邮件）：
   Authentication → Providers → Email → 关掉 *Confirm email*。
3. **实时同步**：`supabase.sql` 末尾已经把 `tasks` 表加入 `supabase_realtime` 发布，
   如果之前手动改过数据库，请重新运行一遍 `supabase.sql`。
4. 若学校网络对 `*.supabase.co` 限速，可以给 Supabase 配一个自己的子域名（自定义域名功能），
   然后把 `.env` 里的 `VITE_SUPABASE_URL` 换成新地址。

## 五、自检清单（改完部署后逐条确认）

- [ ] 手机**关掉 VPN**、用 4G 流量打开新网址，能进入登录页。
- [ ] F12 → Network 里没有任何 `googleapis.com` / `gstatic.com` 请求。
- [ ] 弱网（F12 → Network → Slow 3G）下首屏在 2 秒内出现"正在打开 GroupMate…"骨架。
- [ ] 断网后打开页面，15 秒内出现"连接数据库超时"中文提示 + 重试按钮，而不是一直转圈。
- [ ] 用两个不同账号验证：只看到自己加入的项目，任务互不干扰。
